# Security Policy

## Reporting a vulnerability

Please report security issues privately to **sedat@s3dat.com**. Do not open a public issue.

Include the product name and version, your macOS or iOS version, and the steps to reproduce.
Never send passwords, API keys, verification codes or other secrets.

We will acknowledge your report as soon as possible and keep you updated until it is resolved.

## Scope

This policy covers all S3DAT products and public repositories in the [S3datlab](https://github.com/S3datlab) organization.
